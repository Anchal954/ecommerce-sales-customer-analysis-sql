# E-Commerce Sales & Customer Analysis | SQL

## Overview

Exploratory analysis of e-commerce sales data using SQL Server to understand business performance, customer behavior, product performance and revenue.

## Tools

- SQL Server
- SQL / SSMS

## Analysis

The project answers business questions around:

- Overall sales, orders and customers
- Customer distribution by country and gender
- Revenue by customer and product category
- Top and bottom-performing products
- Sales distribution across countries
- Products and categories with the highest revenue

## SQL Concepts Used

- SELECT, WHERE
- GROUP BY, ORDER BY
- SUM, AVG, COUNT
- COUNT(DISTINCT)
- JOINs
- TOP
- UNION ALL

## Database Tables

- `gold.fact_sales`
- `gold.dim_products`
- `gold.dim_customers`
